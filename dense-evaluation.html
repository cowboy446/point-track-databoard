Protocol

Experiment controls

R00 / D_ALL. No ray loss. Common warmstart, model architecture and frozen layers. Equal weights across the training datasets. Peak learning rate 4e-5.

Two datasets: InternData + LIBERO, 1,024 SV updates followed by 1,024 MV updates. Four datasets: add RoboTwin + RoboCasa, 512 SV updates followed by 512 MV updates. Stride 1 and stride 2 are independent runs.

Frozen inputs

Identical episodes across all eight checkpoints. Input stride matches checkpoint stride. SV checkpoints receive one camera per forward; MV checkpoints retain full multiview input.

Each camera supplies up to 2,048 source points at the first frame. SV queries stay within that camera, with both local view indices set to zero. MV queries cover all target cameras. All queries cover 16 frames.
