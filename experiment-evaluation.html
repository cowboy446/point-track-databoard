Protocol

Frozen samples

Ten task groups per dataset and split, one episode per group. Training and validation groups are disjoint. All checkpoints use identical windows and query IDs within each split. Training episodes use a new frozen query draw.

Source time: first frame. Targets: all 16 frames × three cameras. Source pools are sampled without replacement, with all eligible points retained when fewer than 2,048 are available.

Each checkpoint fits one GT-assisted scale across all nine view pairs in a clip. Camera poses and episode normalization restore meters.

Loss

L=mean⁡ ⁣[c e−0.2log⁡c+0.1 BCE]L=\operatorname{mean}\!\left[c\,e-0.2\log c+0.1\,\mathrm{BCE}\right]L=mean[ce−0.2logc+0.1BCE]

e is the mean absolute signed-log XYZ difference, after separate predicted and GT mean-depth normalization per clip. All models use this same base loss; the additional training ray penalty is excluded. The CSV retains component losses and all query-level metric aggregates.
