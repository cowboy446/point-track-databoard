03 / PROTOCOL

Evaluation protocol

Sampling

Ten distinct development task groups per dataset, one episode each. Windows match the campaign’s central 16-frame, stride-2 windows. Each source uses a frozen uniform sample of up to 2,048 points visible at its first frame and valid throughout the clip. Target time and camera are fully enumerated.

Each clip has up to 3 × 2,048 × 16 × 3 = 294,912 queries. One source pool has only 1,032 eligible points; all are retained, giving 5,849,472 queries in total. Source pools differ by visibility; their point IDs may overlap. No dynamic/static quota or confidence pruning is applied.

Loss

Ls→v=mean⁡s→v ⁣[c e−0.2log⁡c+0.1 BCE]L_{s\to v}=\operatorname{mean}_{s\to v}\!\left[c\,e-0.2\log c+0.1\,\mathrm{BCE}\right]Ls→v​=means→v​[ce−0.2logc+0.1BCE]

e is XYZ L1 after signed-log transformation and separate predicted/GT mean-absolute-depth normalization. Both normalizers use all nine pairs in a clip. Visibility BCE includes occluded queries.

Geometry

One α is fitted over all nine pairs. Camera poses and episode center/scale restore meters. This measures geometry after GT-assisted scale alignment, not independent absolute-scale recovery.

Projection and coverage

Epixel=mean⁡∥π(K pred)−π(K GT)∥2E_{\mathrm{pixel}}=\operatorname{mean}\left\|\pi(K\,\mathrm{pred})-\pi(K\,\mathrm{GT})\right\|_2Epixel​=mean∥π(Kpred)−π(KGT)∥2​

Pixel EPE uses GT-visible queries with finite, positive-depth predictions. Downloads also include coverage and a score assigning invalid projections 10⁶ px. XYZ includes occluded queries. Cross-view disagreement compares the three world predictions for each source track.

Metric details

Development diagnostics, not an independent test score. Clip selection and point sampling were frozen before inference. Playback is slowed to 8 fps; original frame indices and capture rates are retained in the downloads.

04 / ORIGINAL CAMPAIGN

The existing 64-clip dev evaluation

Archived A0 step-2,048 results: up to 16 tracks per class/source, source anchors and 1,024 calibration queries with disjoint point IDs. Each source has 32 tracks, except one with 16; the 64 clips contain 293,376 main queries. Scale is the median paired norm ratio on calibration queries. Geometry errors are divided by mean GT calibration depth. Aggregation balances task groups, then dataset families.

Metric details

The source-pixel P90 is averaged through the task/family hierarchy; it is not a pooled global P90. Motion error removes each trajectory’s temporal mean. These scores use a different query population and alignment from the twenty-clip evaluation above.
